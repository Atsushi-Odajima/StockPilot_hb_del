# SECURITY — セキュリティとプライバシー

## 認証・セッション
- パスワード：scrypt（N=2^15, r=8, p=1, 16バイト塩）、10文字以上。存在しないメールでも同程度の計算を行う。
- セッション：32バイト乱数トークンを HttpOnly・SameSite=Lax（本番 Secure）Cookie に保存。DBには sha256 のみ。30日で失効。ログアウト・全セッション失効・パスワード変更・再設定で失効。
- パスワード再設定：30分・1回限りのトークン（sha256保存）。メール送信は `mailer` 差し込み口のみ実装（本番の送信サービスは未契約＝**残作業**）。
- 認証系 API は 10回/分/IP、全体は 600回/分/IP（環境変数で変更可）。
- 初版は認証を自前実装（DECISIONS.md D-03）。管理型認証サービスへの移行は残作業候補。

## 認可・事業者分離
- 全業務データはワークスペースID（事業者のデータ世代）でスコープ。サーバーは常に `ws_id = セッションから解決した世代` で問い合わせ、複合外部キーで親子参照も同一ワークスペースに制限。
- URL・CSV・QR・帳票・画像のIDを書き換えても 404（存在も明かさない）。`tests/api.test.ts` T26 で検証。
- 運営用の利用権付与は `npm run admin`（サーバー上のCLI）のみ。ブラウザから運営権限を得る経路はない。
- クライアントに DB 接続情報・運営キーは渡さない（サーバー単体構成、サービスロール鍵なし）。

## 入力・出力
- すべての入力を zod で検証（長さ・件数・整数・日付）。SQL はすべてパラメータ化（動的なのはコード内固定の列名・テーブル名のみ）。
- アップロード：写真は先頭バイトで JPEG/PNG/WEBP を判定（HTML/SVG/HEIC は拒否）、8MB。CSV 5MB。バックアップ ZIP 500MB、展開サイズ・件数・ファイル名許可リスト・パストラバーサル拒否。復元時も画像の実体を検査。
- 写真は認証付き `/api/files/:id` から `Content-Type`＋`nosniff`＋`private` で配信。公開URLはない。
- CSV 出力：BOM付きUTF-8、文字列は常に引用、`= + - @ タブ CR`（全角含む）で始まる文字列は先頭に `'` を付けて数式実行を防止。数値は検証済みの number のみ。
- 帳票：スナップショットの許可項目だけを描画（内部メモ・内部ID・連絡先詳細・パスは含めない。T30）。任意URL・HTMLを読み込まない（pdfkit で直接描画）。

## CSRF・XSS・ヘッダー
- 状態変更要求は独自ヘッダー `x-stockpilot-csrf: 1` 必須＋Origin 一致。CORS は無効（別オリジンから独自ヘッダー付き要求は送れない）。
- CSP：`default-src 'self'`、script は self と `wasm-unsafe-eval`（端末内デコーダ）、object 禁止、frame-ancestors none。React の自動エスケープ、`dangerouslySetInnerHTML` 不使用。
- helmet 既定ヘッダー、本番は HSTS。API 応答は `no-store`。

## PWA・端末
- Service Worker は外枠（HTML・ハッシュ付き資産・アイコン・wasm）のみキャッシュ。`/api/` は一切キャッシュしない。
- 端末下書きは IndexedDB にアカウント識別子付きで保存し、別アカウントには表示しない。ログアウト時に件数を警告。アカウント削除時は削除。

## ログ・監査
- Fastify ログは Cookie・Authorization・Set-Cookie を伏せる。本番は要求ログを出さない。エラーはメッセージとコードのみ。
- audit_log：登録・ログイン成否・パスワード変更・バックアップ・復元・利用権付与。業務データ本文・CSV本文・連絡先・パスワードは記録しない。

## 外部送信
- 銀行・EC・メール・SNS・外部AIへの接続なし。カメラ映像は端末内で処理（ネイティブ BarcodeDetector または自前配信の zxing-wasm）。CDN からの読込なし。

## 画面の説明文（実装と一致）
「業務データはアカウント専用のクラウド領域に保存されます。カメラのコード読み取り映像は端末内で処理します。商品写真は選択して登録したものだけ保存します。」
